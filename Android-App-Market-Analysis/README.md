# Android App Market Analysis

## Project Overview

This project analyzes Google Play Store applications to uncover trends in app categories, ratings, installs, pricing, and user sentiment. The objective is to understand market dynamics and provide business insights for developers and stakeholders.

---

## Problem Statement

Analyze Google Play Store data to identify popular categories, highly rated apps, install patterns, pricing trends, and user sentiment.

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dataset

### apps.csv
Contains:
- App Name
- Category
- Rating
- Reviews
- Installs
- Price
- Type
- Genres

### user_reviews.csv
Contains:
- App
- Sentiment
- Sentiment Polarity
- Sentiment Subjectivity

---

## Project Workflow

### Data Cleaning
- Removed unnecessary columns
- Handled missing values
- Converted installs and price to numeric format

### Exploratory Data Analysis
- Top Categories
- Rating Distribution
- Free vs Paid Apps
- Popular Genres
- Install Trends

### Sentiment Analysis
- Sentiment Distribution
- Most Loved Apps
- App Review Analysis

---

## Key Insights

- Free apps dominate the Google Play Store.
- Some categories consistently achieve higher ratings.
- A small number of apps generate most installs.
- User sentiment provides valuable feedback on app quality.

---

## Recommendations

- Focus on high-growth categories.
- Improve low-rated applications.
- Use sentiment insights for product improvements.
- Explore monetization opportunities in popular categories.

---

## Conclusion

This project demonstrates how data analytics can be used to understand app market trends and user preferences, helping developers make data-driven decisions.
