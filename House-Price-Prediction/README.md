# House Price Prediction Using Linear Regression

## Project Overview

This project uses Linear Regression to predict house prices based on various housing features such as area, bedrooms, bathrooms, parking, furnishing status, and other amenities.

---

## Problem Statement

The objective is to build a machine learning model capable of predicting house prices and identifying the key factors that influence property values.

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

---

## Dataset Features

- Price
- Area
- Bedrooms
- Bathrooms
- Stories
- Main Road
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Parking
- Preferred Area
- Furnishing Status

---

## Project Workflow

### Data Preprocessing
- Missing value check
- Encoding categorical variables

### Exploratory Data Analysis
- Correlation analysis
- Feature relationship analysis

### Model Building
- Train-Test Split
- Linear Regression

### Model Evaluation
- R² Score
- Mean Squared Error (MSE)

---

## Results

- R² Score: 0.653
- Model explains approximately 65% of house price variation.

---

## Key Insights

- House area strongly influences price.
- Additional bathrooms and parking increase value.
- Air conditioning and furnishing status contribute positively to pricing.
- Multiple housing features collectively affect market value.

---

## Conclusion

The Linear Regression model successfully predicted house prices with good accuracy and demonstrated how machine learning can support real estate decision-making.
