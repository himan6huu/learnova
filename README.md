# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to identify customer purchasing behavior, sales trends, and product performance. The analysis helps uncover meaningful business insights that can support data-driven decision-making.

---

## Objectives
- Analyze customer purchasing patterns
- Identify top-performing product categories
- Study sales trends and customer demographics
- Generate business insights and recommendations

---

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dataset Features
The dataset contains:
- Customer information
- Gender
- Age
- Product Category
- Quantity Purchased
- Price per Unit
- Total Amount

---

## Key Analysis Performed
### Data Cleaning
- Checked missing values
- Removed duplicates
- Verified data types

### Exploratory Data Analysis
- Sales by product category
- Gender-wise sales analysis
- Age distribution analysis
- Age-group purchasing behavior
- Top-selling product categories
- Average order value analysis

---

## Key Insights
- Certain product categories generated the highest revenue.
- Middle-aged customers contributed significantly to total sales.
- Purchasing behavior varied across customer demographics.
- High-demand categories showed stronger sales performance.

---

## Recommendations
- Focus marketing on high-performing categories.
- Improve inventory management for frequently purchased products.
- Use customer demographic insights for targeted promotions.
- Increase engagement strategies for underperforming categories.

---

## Conclusion
This project demonstrates how Exploratory Data Analysis (EDA) can be used to extract valuable business insights from retail sales data. The findings can help businesses improve customer engagement, optimize sales strategies, and make informed decisions.
